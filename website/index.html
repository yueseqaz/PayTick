功能特性

一切为了让你更清楚地知道自己在赚什么

⏱️

实时工资追踪

菜单栏每秒更新今日已赚金额，上下两行紧凑布局——倒计时在上，工资金额在下

🧭

状态感知菜单栏

上班前显示"还未上班"，午休显示"午休中"+已赚金额，下班后显示"已下班"，周末显示"周末休息"

📅

考勤管理

月历视图手动打卡，整格可点击、悬停高亮，右键一键清除当天，5 种考勤状态，数据持久化在本地

📊

Excel 导出

纯 Swift 手写 OOXML 生成 .xlsx 文件，支持本月/本年/指定日期范围导出，状态颜色 + 周末合并 + 统计汇总

🔔

下班提醒

下班前 N 分钟系统通知 + 菜单栏金额变橙色，提醒分钟数 1-60 可调，同日去重不重复通知

🌐

双语 UI

运行时切换 English / 简体中文，重启保留，菜单栏、弹窗、考勤窗口全部本地化
